# Design System Master File — Abrar Junaed Portfolio

> **LOGIC:** Global UI/UX Pro Max Source of Truth (`Minimalism & Swiss Style` — Zero Gradients, Zero Card Bars).

## 1. Visual Direction & Typography
- **Style:** Swiss Editorial / Geist Monochrome (Zero gradients, zero decorative card stripes, hairline `1px` borders, `1100px` editorial grid).
- **Heading Font:** `Space Grotesk` (600)
- **Body Font:** `DM Sans` (400, 500, 600)
- **Monospace Font:** `JetBrains Mono` (400, 500) — used sparingly for numeric indices (`01`–`09`), spec labels, and tech tags.
